# CampAssault

SE3032 – Graphics and Visualization  
Interactive 3D Shooting Game

## Project Overview

CampAssault is a first-person 3D shooting game developed using Unity. The player travels through a forest road and checkpoint towards a military camp while engaging AI-controlled enemies.

The project includes environment design, player interaction physics, enemy movement and animations, shooting mechanics, custom 3D models, and interactive objects.

## Unity Version

Unity 6.6 (6000.6.7f1)

## Main Scene

`Assets/Scenes/CampScene.unity`

## Main Features

- First-person player movement
- Automatic shooting system
- Enemy patrol, detection, chase and combat
- NavMesh-based enemy movement
- Enemy animations and death system
- Player health and Game Over system
- Interactive camp gate
- Pushable crates
- Pick-up and throwable objects
- Military camp environment
- Terrain, trees, grass and bushes
- Custom 3D models created in Blender
- UI crosshair and health bar

## Controls

- W, A, S, D – Move
- Mouse – Look around
- Left Mouse Button – Shoot
- E – Interact / open gate
- F – Pick up / drop throwable object
- G – Throw held object

## Custom 3D Models

Custom models created using Blender include:

- Camp entrance sandbag barricades
- Watchtower
- Checkpoint sandbag barriers

## Third-Party Assets

The project uses several free assets obtained from the Unity Asset Store.

Some third-party asset folders are excluded from this public GitHub repository to avoid redistributing external asset packages.
